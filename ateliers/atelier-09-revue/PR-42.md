# PR n° 42 · Téléchargement des documents signés

**Auteur** : un collègue pressé, aidé par un assistant IA · **Cible** : `main` · **Statut** : à relire

## Description

> Ajoute le téléchargement des PDF signés : on reçoit le nom du fichier dans l'URL,
> on vérifie l'empreinte avant l'envoi, on affiche la taille et on bloque le
> téléchargement après la date d'expiration. Code généré, ça marche chez moi, à merger vite 🙏

## Fichiers modifiés

| Fichier | Rôle |
|---|---|
| `pr-42/telechargement.js` | construit le chemin du fichier demandé |
| `pr-42/verification.js` | compare l'empreinte SHA-256 du fichier à celle du registre |
| `pr-42/taille.js` | affiche la taille du fichier |
| `pr-42/expiration.js` | dit si le document peut encore être signé |
